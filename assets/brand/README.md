# V-Clicker brand

Butter-yellow paper collage: cut card and paper, cream, soft gold and graphite. Every image has a transparent
background.

| File | Use |
|---|---|
| `app-icon.png` | **The official logo and app icon** (graphite V on a cream card). `../icon.ico`, `../icon.png` and `../icon-256.png` are made from it (window, taskbar, tray, `.exe`, the app header). |
| `logo-horizontal.png` | The name as a sticker: README header, top bars. Reads on light and dark backgrounds. |
| `logo-torn-paper.png` | The name on torn paper with tape: headers, landing pages. |
| `banner-editorial.png` | The name on a paper strip with a click burst: home and help pages. |
| `emblem-paper.png` | Yellow V and cursor on a round paper collage: splash, about, `../social-preview.png`. |
| `monogram-orbital.png` | The V with an orbit and a cursor: watermarks, empty states. |
| `cursor-click.png` | A clicking cursor: action screens, tutorials. |
| `click-seal.png` | A cursor seal: onboarding, automations. |
| `settings-gear.png` | A gear with a cursor: settings. |
| `cloud-cursor.png` | A cursor on a cloud: notifications, promotional art. |

Colours (sampled from the art): butter yellow `#F9BE4C`, soft gold `#DC9C37`, cream `#FAE7C9`, card `#F0DBBA`,
graphite `#2C251F`.

The images are raster cut-outs of one composition (the largest is 757 px wide); a redrawn SVG set would be needed for
large print or pixel-perfect scaling.
