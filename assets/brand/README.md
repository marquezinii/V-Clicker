# V-Clicker brand

| File | Use |
|---|---|
| `app-icon.png` | The app icon (rounded square), full size. `../icon.ico`, `../icon.png` and `../icon-256.png` are made from it. |
| `logo-horizontal-color.png` | Mark + name, for dark backgrounds (README in dark mode). |
| `logo-horizontal-navy.png` | Mark + name in navy, for light backgrounds (README in light mode, print). |
| `logo-horizontal-white.png` | Mark + name in white, over photos or colour. |
| `logo-vertical.png` | App icon over the name. |
| `mark-color.png`, `mark-glossy.png`, `mark-neon-outline.png` | The symbol alone (V + cursor). |
| `wordmark-glossy.png`, `wordmark-rounded.png`, `wordmark-light.png` | The name alone (`../social-preview.png` uses the glossy one). |

Colours: cyan `#22E6FF` → blue `#2563FF` → violet `#B05CFF` on navy `#0B1022`.
